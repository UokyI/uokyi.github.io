Privacy Policy

Last updated: October 23, 2026

WebCut (known in Chinese as 网页截图标注) ("we", "our", or "this extension") is a browser extension for Microsoft Edge that captures and annotates elements on web pages. You can pick any element, capture its complete content (automatically scrolling and stitching tall elements), and mark it up with arrows, boxes, text, and pixelation. This privacy policy explains what data we collect and how we use it.

Data Collection

We do NOT collect any personal data.

This extension has no account system, no analytics, no advertising, and no tracking of any kind. It does not read, modify, or track the web pages you visit except when you explicitly invoke it to capture an element. Screenshots and annotations are processed locally and are never uploaded.

How the Extension Works

WebCut runs entirely in your browser. When you click the extension icon, use the right-click menu, or press the keyboard shortcut, the extension temporarily accesses the active tab through the activeTab permission and injects an element picker. You hover over the page to highlight an element and click to capture it.

If the selected element is taller than the viewport, the extension scrolls the page in segments, captures each segment, stitches them into one image, and then restores your original scroll position. The captured image opens in a local editor, where you can add annotations and export a PNG or copy it to the clipboard. The extension does not run on websites in the background.

Data Storage

The extension uses Chrome's local storage (chrome.storage.local) to save only:

  • The id of the most recent capture, so the “Last capture” button can reopen it
  • Your editor preferences (corner style, spacing, background, shadow, annotation color, weight, and text size)

Screenshots and annotations are stored as Blobs in the browser's IndexedDB on your local device. The extension periodically removes old captures. Uninstalling WebCut or clearing the extension's site data removes this local data. None of it is uploaded, synchronized, or shared.

Permissions

  • activeTab - Grants temporary access to the current tab only when you explicitly invoke WebCut from the toolbar, context menu, or keyboard shortcut.
  • scripting - Used solely to inject the element picker into the current page.
  • contextMenus - Used solely to register the “WebCut: pick an element to capture” right-click menu item.
  • storage - Used solely to remember the last capture id and your editor preferences locally.
  • clipboardWrite - Used only when you click “Copy” in the editor, to write the annotated PNG to the clipboard. The extension never reads clipboard contents.

The extension requests no host_permissions, so it cannot access or read web content in the background.

Data Transmission

This extension does not transmit any data to any server. There is no cloud service, no telemetry, no tracking, no analytics, and no third-party communication of any kind. It does not use remote code; all scripts, styles, fonts, and icons are bundled with the extension.

Third-Party Services

WebCut does not use any third-party analytics, advertising, tracking, cloud storage, or external APIs.

Scope and Limitations

WebCut cannot run on browser-internal or protected pages, such as edge://, chrome://, the add-on store, or the built-in PDF viewer. Elements inside cross-origin iframes cannot be picked directly. When stitching tall elements, fixed or sticky navigation bars may appear in more than one segment; this is a visual limitation of the capture process, not a data collection feature.

Children's Privacy

This extension does not knowingly collect any data from children or any other users.
